# AM-SyncedHeartbeat

Patch for [Dynamic Moodles](https://www.nexusmods.com/scavprototype/mods/864?tab=description) that makes Critical Style "AlarmHop" sync to player's heartbeat

More severe moodles bounce up more
Fibrilation will make bounces weaker and weaker, until they stop

Inspired by [Fading Vitality](https://youtu.be/AuJA9BKGDVE?t=42)'s moodle animation
